# Okta Verify — página de descarga

Página estática para que nuevos empleados descarguen Okta Verify durante la inducción.

## Publicar en GitHub Pages

1. Sube estos archivos a un repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`, luego guarda.

GitHub mostrará la URL pública de la página al terminar la publicación.
